# Brand Breakdown

> **“Behind every great brand is a strategy. Let’s break it down.”**

A modern, responsive digital marketing and business publication created as an academic project by a first-year **BBA Digital Business** student. The website explores how the world's most recognisable brands build identity, attract customers, execute creative campaigns, and win in competitive markets.

---

## 🚀 How to Run Locally

### Prerequisites
- Node.js (version 18 or higher recommended)
- npm (comes with Node.js)

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) (or the port specified in terminal output) in your web browser.

---

## 🛠️ How to Build for Production

To create an optimized production build:
```bash
npm run build
```
This will compile all TypeScript and React assets into the `dist/` directory.

## 🌐 How to Deploy on Vercel (100% Free)

Deploying Brand Breakdown to Vercel requires zero complex configuration and runs on Vercel's free tier:

1. **Push to GitHub**:
   - Push this codebase to a repository on your GitHub account (e.g., `brand-breakdown`).
2. **Open Vercel**:
   - Go to [vercel.com](https://vercel.com) and log in using your GitHub account.
3. **Import Project**:
   - Click **Add New...** &rarr; **Project**.
   - Select your `brand-breakdown` repository.
4. **Configure Settings**:
   - Framework Preset: Vercel automatically selects **Vite**.
   - Root Directory: `./` (leave default).
   - Build Command: `npm run build` (leave default).
   - Output Directory: `dist` (leave default).
   - Environment Variables: **None required** (the project is self-contained with no paid API keys needed).
5. **Deploy**:
   - Click **Deploy**. Your website will be live in ~45 seconds on a free `brand-breakdown.vercel.app` URL.
